Connect your browser to UDM

UDM is installed and its desktop connection is already registered. Add the browser extension below to send downloads and supported media to UDM.

Choose your browser. The bundled Chromium extension works with Chrome, Microsoft Edge, and compatible Chromium browsers. Firefox uses its own bundled folder.

Chrome, Edge, Brave, or Chromium

  1. Copy the address for your browser below, paste it into its address bar, and open it.
  2. Turn on Developer mode.
  3. Select Load unpacked.
  4. Select the installed browser\chromium folder inside your UDM installation folder.
  5. Open the UDM extension and choose Check desktop connection.

Firefox

The bundled Firefox add-on is currently a development build. Firefox can load it temporarily for the current browser session:

  1. Copy the Firefox debugging address below, paste it into Firefox’s address bar, and open it.
  2. Select This Firefox, then Load Temporary Add-on.
  3. Select browser\firefox\manifest.json inside your UDM installation folder.
  4. Open the UDM extension and choose Check desktop connection.

Need help?

Close and reopen the browser after adding the extension if it cannot find the desktop connection. The extension only transfers a download when you choose a UDM action or enable its supported capture behavior.
