The staged 6.19 Windows executable ran five isolated HTTP/1.1 cases. Matching checksums published byte-identical 64 KiB and 12 MiB files. Mismatches at both sizes failed before publication and retained all received bytes. A malformed digest was ignored. The 64 KiB cases each made one GET. The 12 MiB cases made one full GET and three range requests, with deliberately unrelated `Content-Digest` values on the partial responses. The extension fixtures passed 81 HLS, 42 indexed DASH, and 44 external DASH checks. An isolated Edge profile also passed native HLS downloads in MP4, TS and M4A.
