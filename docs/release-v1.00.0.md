# UDM 1.00.0 — browser integration 0.63.7

UDM 1.00.0 packages the desktop source at `7023dcdeecb5b788a0cd368c372c2c0bbebe0e04`. This release expands browser-to-native capture and recovery, including rendered page links in Site Grabber, durable original-response admission, and explicit recovery of interrupted captures. It also includes proxy and mapped-address routing fixes, media and caption recovery, and installer lifecycle safeguards. The browser extensions retain their separate version number, 0.63.7. See the [detailed changes since RC3](changelog-rc3-to-100.md).

The exact native test executable passed 2,599 checks. The rendered-capture browser unit fixtures passed 18 checks; real Edge passed three isolated extension checks and five Edge-to-native checks. A production-derived installer fixture passed 35 install, repair, and uninstall checks with private registry roots and preserved download history. The signed network runtime passed its status/integrity check. The 61,559,710-byte installer has SHA-256 `CDC8B2E33511FA7EFA52BA4C6453E192C12013356B51B22D569B9A5FA3BD09EE`. See [machine-readable verification](validation/release-100-20261011.json).

The native suite's first restricted run stopped after 107 passes at Windows socket error 12029; the same executable passed all 2,599 checks with local socket access. The production installer was compiled but not installed into the personal application location. The isolated lifecycle fixture does not establish a machine-wide administrative upgrade. Broad public-site compatibility, live elevated-driver capture, and complete IDM behavior or appearance parity remain unverified.
