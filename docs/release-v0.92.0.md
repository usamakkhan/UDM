# UDM 0.92.0

This cumulative release advances from UDM 0.91.0 with publication-time content recognition and faster recovery of saved publication and link state.

## Safer completion publication

- Inspect downloaded content before publishing a completed file so completion handling has a stronger view of what was retrieved.
- Retain the existing protected publication and verification workflow while adding this recognition step.

## Faster recovery

- Reduce the work required to recover saved publication records and links.
- Keep recovery behavior focused on the persisted state, avoiding avoidable repeated scans.

## Verification

This installer is built from the tagged source. The release notes describe the implemented scope; full IDM parity remains unfinished.
