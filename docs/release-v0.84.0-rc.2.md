# UDM 0.84.0 RC2 — browser 0.62.13

RC2 packages the source changes since [RC1](https://github.com/usamakkhan/UDM/blob/v0.84.0-rc.2/docs/changelog-rc1-to-20261008-push.md), through product commit `b2a10af`. It includes live and recorded HLS WebVTT captions, gzip/Brotli streaming support, browser panel and navigation recovery, native dialog and scheduler improvements, and signed-network playlist recognition, failed-handoff forwarding, and scoped process-attributed observations through the desktop broker. It also shows the active list sort direction and fixes required-step handling in silent installer runs. Native files report 0.84.0; both browser manifests report 0.62.13.

The installer asset is `UDM-0.84.0-Browser-0.62.13-RC2-Setup-x64.exe` (61,322,215 bytes; SHA-256 `6165E373621A5F993C3C29BB08335869D9032157D757F790D9A6C4C0F468319D`). It was compiled with Inno Setup 6.7.3 from an isolated staging tree. The application, native host, monitor, setup helper, browser bundles, notices, FFmpeg tools, and signed network runtime were staged together. The network helper's runtime/protocol status check passed. The installer is not publisher-signed.

Validation of this source cut: the fresh native app and companions built successfully. The broker-integrated full native suite passed all 2,572 checks. The later sort-header-only app rebuild also passed. The rebuilt signed-network helper passed 73 core checks and the broker protocol receipt records 37 passing checks. Current browser source passed 27 navigation, 23 HLS handoff, 18 HLS catalog, and 31 audio/subtitle checks. Existing focused GUI evidence covers the tab-keyboard candidate (133 Options and 129 shared-dialog checks), the sort-header candidate (365 menu/workflow and 183 render/shared-dialog checks), and the installer required-step fixture (seven cases); the recorded-caption candidate and media-refresh fixtures have separate Edge/Firefox receipts. These focused results do not constitute a fresh real-browser run of the exact RC2 installer.

This is a prerelease. The installer was not executed, installed, publisher-signed, or tested through a clean-machine upgrade/rollback lifecycle. The existing personal installation was not replaced. Public-site compatibility, broad driver behavior, and complete IDM parity remain unqualified.
