# HLS delta update validation (2026-10-14)

This change lets live HLS recordings merge `EXT-X-SKIP` delta playlists with retained segment history. When the first response is a delta without that history, UDM requests a complete playlist after removing `_HLS_skip`, `_HLS_msn`, and `_HLS_part` delivery directives. Browser catalog reads do the same and retain an already observed complete playlist. Other query parameters remain intact.

The behavior follows the [IETF HLS second-edition draft](https://datatracker.ietf.org/doc/draft-pantos-hls-rfc8216bis/19/) and [Apple's low-latency HLS documentation](https://developer.apple.com/documentation/http-live-streaming/enabling-low-latency-http-live-streaming-hls).
