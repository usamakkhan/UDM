# Content detection: malformed UTF-8 — 18 October 2026

UDM's text classifier accepted three- and four-byte overlong UTF-8 encodings, surrogate encodings, values above U+10FFFF, and incomplete sequences at actual EOF. Because text detected under a binary filename triggers the web-page guard, these bytes could falsely stop a download. This was found by source review, not by an IDM differential test.

The classifier now enforces the second-byte bounds from [RFC 3629 section 4](https://www.rfc-editor.org/rfc/rfc3629#section-4). A potentially valid sequence cut by the bounded sniff window remains acceptable; an already-invalid sequence is rejected even at that boundary. Incomplete sequences at the actual end of the file are no longer treated as valid text. Normal HTML detection is retained.

The shared `ContentSniffUnicodeChecks.hpp` exercises valid scalar boundaries, malformed encodings, EOF truncation, window truncation, and the binary-download error decision. Before the fix: 21 passed, 20 failed. After: 41 passed, zero failed. Logs are `content-unicode-before-20261018.txt` and `content-unicode-after-20261018.txt`. These are focused in-process classifier checks, not transfer or installed-app validation.

The same checks are included in the existing `--content-sniff-checks` suite, with two new loopback transfers asserting byte-for-byte publication of malformed UTF-8 without a false web-page error, below and above the sniff-window size. All 116 focused content checks passed, including actual HTML rejection and the existing prefix/rename checks; see `content-unicode-integration-20261018.txt`. The desktop was relinked successfully with the rebuilt transfer object and the previously validated unchanged UI object. A full clean build and full native suite were not run. The candidate was subsequently installed after elevation. The installed hash matches the candidate, UDM reopened normally, and all 28 download IDs, statuses and sizes remained unchanged. The previous executable was backed up. Startup was checked live; the transfer checks above used the isolated native harness.
