# Desktop, Site Grabber, and recovery qualification

November 7, 2026. This pass follows [P4–P6 of the architecture plan](../idm-parity-architecture-plan.md). It uses private catalogs, loopback fixtures, and a fresh Edge profile. The existing installations and personal downloads were outside the test scope.

## P4 Desktop and queues

UDM 5.24 reproduced a missing wake request. A daily queue had paused work and was scheduled to open at a specific second. Its disabled stop time happened to match the start time. The wake planner treated the saved times as a continuously open window and reported `Waiting`.

UDM 5.25 uses the same effective daily stop time in both the queue runner and the wake planner. A disabled stop uses the end of the day. Equal times still represent a continuously open window when the stop is enabled. A repeat with the staged 5.25 app reported `Armed` for the correct queue at the exact selected second. The check establishes timer registration while Windows is awake.

The staged 5.24 and 5.25 desktops accepted a paused Internet Shortcut and a paused URL-scheme command into the same private Main queue. Neither made a network request before the CLI started the queue. The two resulting files matched the origin SHA-256. The 5.25 queue completion fixture passed 15 checks.

The current native Scheduler dialog fixture, physical sleep and wake, and matched-DPI comparison against IDM remain open.

## P5 Site Grabber and Windows integration

- The rendered capture handoff passed 18 native-message checks on staged 5.24, including project matching, durable request and receipt handling, cancellation, and preservation of the protected last successful capture.
- Five real Edge-to-native checks passed on both 5.24 and 5.25 using a minimal harness with the production collector and native bridge. The harness lost one acknowledgement after a real save. It recovered by querying the receipt, with one submission and one new project generation. Three further Edge collector checks verified that reloading the same URL invalidates the old document and enables a fresh capture.
- Six focused suites passed for rendered popup, background routing, cancellation, handoff and document identity. The eight Explorer source checks passed. The direct shortcut and URL-scheme test invoked the staged executable without writing the Windows registrations.
- The 5.25 rendered archive fixture passed 48 native checks, including pause and catalog reopen, cached response reuse, asset rewriting, and exact media bytes. FFmpeg decoded the complete saved video and audio. After the origin stopped, Edge passed 15 archive checks and followed the saved child page and back link. The archive-only browser run made zero requests outside the archive server.
- The wizard's current visual comparison, Windows Explorer menu activation, installed browser host repair, and machine-wide COM activation remain open.

## P6 Recovery and release

The staged 5.24 and 5.25 setup helpers each passed 12 isolated checks covering custom history discovery, conflicts, locked configuration, rollback and idempotence. The catalog and partial file hashes survived every operation.

The 5.25 publication recovery fixture passed 38 checks. It covered locked backup state, a failed destination rename, restart after verified bytes had been published, a destination that was changed by the user, and removal of a reconciled record while preserving its file. The restore fixture passed 59 checks, and two more verified HTTP range resume and an exact final hash after restore. A separate process exited after installing a fixture file. Recovery reopened its journal and restored every original.

The first 5.25 native compile and the simultaneous native fixture compile stopped after MSVC ran out of heap. A serial production retry succeeded. All five 5.25 executable hashes and 76 recorded source-input hashes matched the [native build receipt](scheduler-wake-window-5.25-build.json). The candidate manifest under `candidates/scheduler-wake-window-5.25/stage-manifest.json` records 143 staged files, including both browser bundles at 0.68.89, the type library, assets, and notices. It also identifies the separately stored FFmpeg and FFprobe by version and hash. All 64 staged JavaScript files passed syntax checks. The native executables are unsigned.

A public release still requires publisher signing, signed update-manifest verification with the release key, clean Windows installation, upgrade and rollback, repair and removal, and broader P1–P6 acceptance. No setup package or publication was part of this pass.

Raw 5.25 fixture receipts are under `candidates/p4-p5-p6-5.25/`. The active branch advanced during compilation. The successful retry recorded source commit `d54c1cdb`, and every recorded source input matched its pre-build hash.
