# UDM 0.87.0 — browser integration 0.63.8

UDM 0.87.0 packages the current desktop source with browser integration 0.63.8. It includes browser-to-native capture and recovery, rendered page links in Site Grabber, durable original-response admission, explicit recovery of interrupted captures, proxy and mapped-address routing fixes, media/caption recovery, installer lifecycle safeguards, and safer handling of same-document video navigation. See the [detailed changes since RC3](changelog-rc3-to-087.md).

The 0.87.0 installer is built from this tagged source and is the only release asset. The previous 1.00.0 prerelease and its installer are withdrawn rather than being relabeled as 0.87.0. Historical validation records remain in the repository as development evidence, but they do not substitute for the 0.87.0 package identity.
