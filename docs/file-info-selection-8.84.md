# File Info selection freshness — UDM 8.84

UDM 8.84 / extension manifests 0.72.48 separates accepted request identity from the File Info rendering cache. A size, title, content-type or folder-history refresh no longer rejects an otherwise unchanged accepted video. The dialog keeps the destination and description already edited by the user.

The private immutable selection contains source/request URLs, protected request and adaptive/SABR inputs, output choice and track presence/identity. The reader compares borrowed current values under the existing model lock without recapturing preferences, categories or large protected plans. Receipt fingerprint, accepted status, job membership, outstanding presentation, individual-start and Cancel/attach checks remain required. Legacy synthetic views without a selection retain the previous strict rendering comparison. Selection values stay inside the process; they are never included in the public evidence.
